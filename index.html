About

I'm a Java backend developer based in Kochi, working on the kind of systems that have to be right the first time — regulatory workflows, financial reconciliation and back-office platforms where a failed file upload is a compliance problem, not just a bug.

Most of my day is spent in Spring Boot microservices and Kafka consumers: designing REST APIs for core financial operations, integrating external systems such as NSDL and CKYC over secure token-based auth, and building fault-tolerant file processing with automated retry, recovery and self-healing behaviour. I also automate the batch jobs and schedulers that move high volumes of files overnight.

I've migrated legacy modules into microservices, containerised services with Docker, and spent enough time debugging on OKD/OpenShift — log analysis, API testing, database queries — to have a real appreciation for observability and clean failure handling.
